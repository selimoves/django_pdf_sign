# Дорожная карта

## 1.0

- Замороженный публичный API (`docs/api.md`).
- Поддержка Django 5.2 LTS, 6.0 и 6.1.
- Покрытие ветвей не ниже 90%.
- Внутреннее security-ревью, fuzzing парсеров ASN.1.
- Сайт документации, cookbook и запускаемый пример.
- Публикация через PyPI Trusted Publishing.

## После 1.0

- Полноценная поддержка нескольких подписей: список подписей, выбор и проверка
  каждой, отображение цепочки.
- Асинхронное завершение подписи для больших документов ГОСТ.
- Клиент TSA для получения меток времени, а не только проверки.
- Готовые представления и шаблоны для типового сценария подписи.
- Расширенная диагностика: причины отказа цепочки человеческим языком.

Порядок и сроки не гарантируются. Предложения — через issues.
