# Политика версий

Пакет следует [семантическому версионированию](https://semver.org/lang/ru/).

## Правила

- **MAJOR** — несовместимое изменение публичного API (см. `docs/api.md`).
- **MINOR** — новая обратносовместимая функциональность, а также объявления об
  устаревании.
- **PATCH** — обратносовместимые исправления и обновления документации.

## Депрекации

- Удаление публичного имени проходит через минорный релиз: сначала имя
  помечается устаревшим и вызывает `DeprecationWarning`.
- Имя остаётся рабочим минимум один минорный релиз после объявления.
- Удаление допускается только в следующем мажорном релизе.

## Поддержка

- Поддерживаются текущая и предыдущая минорные версии.
- Поддерживается последняя LTS-версия Django из матрицы (см. `SUPPORT.md`).
- Исправления безопасности выпускаются для поддерживаемых версий; порядок
  раскрытия описан в `SECURITY.md`.

## Совместимость

- Минимальная версия Python и Django фиксируется в `pyproject.toml`.
- Внутренние модули (`crypto.*`, `pdf.*`, `services.prepare`,
  `services.complete`, `services.verify`) не подпадают под гарантии SemVer.
