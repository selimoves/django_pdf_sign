# Пример: подпись PDF в браузере

Минимальный Django-проект: загрузка PDF, подготовка, подпись плагином
КриптоПро, встраивание CMS.

## Запуск

```powershell
cd examples
uv run python manage.py migrate
uv run python manage.py runserver
```

Откройте <http://127.0.0.1:8000/>, выберите PDF и сертификат.

Требуется Windows с установленным КриптоПро CSP и сертификат в личном
хранилище. Без плагина серверная часть всё равно запускается.

## Что внутри

- `signatures/views.py` — загрузка, подготовка, завершение.
- `signatures/templates/signatures/index.html` — браузерный клиент.
- `demo/settings.py` — минимальные настройки Django.

Пример использует SQLite и `FileSystemStorage`, не проверяет авторизацию и
годится только для локального запуска. В продакшене добавьте права, приватное
хранилище и HTTPS.
