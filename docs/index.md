# django-pdf-sign

Клиентские электронные подписи PDF-документов в Django.

- **Сервер не хранит закрытые ключи.** Подпись создаётся в браузере плагином
  КриптоПро; сервер готовит документ, проверяет CMS и встраивает её.
- **ГОСТ Р 34.10-2012 / CAdES-BES** — квалифицированные подписи.
- **PAdES / RSA-ECDSA** — подписи, совместимые с Adobe.
- Видимый штамп, проверка цепочки, CRL, OCSP и меток времени.

## Возможности

- `prepare_signing` — PDF со штампом и точные байты для подписи.
- `complete_signing` — проверка отсоединённой CMS и встраивание.
- `verify_signed_pdf` и `verify_cms_over_bytes` — проверка подписей.
- Модели `SigningSession` и `SignatureRecord`, админка и команда очистки.

## Установка

```powershell
uv add django-pdf-sign
```

Добавьте приложение и настройки — см. [быстрый старт](quickstart.md).
