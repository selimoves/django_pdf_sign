# Журнал изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [семантическому версионированию](https://semver.org/lang/ru/).

## [Unreleased]

## [1.0.0] - 2026-11-08

Первая стабильная версия. Публичный API заморожен; правила совместимости — в
`docs/api.md` и `docs/versioning.md`.

### Добавлено

- `verify_signed_pdf(..., signature_index=...)` — проверка выбранной подписи.
- `VERIFY.FETCH_ALLOWED_HOSTS` и allowlist-фильтр для сетевой загрузки CRL,
  OCSP и цепочек.
- Django system checks для `DJANGO_PDF_SIGN`: ошибки конфигурации видны при
  старте.
- События `session_prepared`, `signing_completed`, `verification_failed` и
  обработчик `ON_EVENT`.
- Сайт документации на MkDocs, cookbook, справочник настроек, FAQ и
  запускаемый пример.
- Документы по безопасности: политика, модель угроз и внутреннее ревью.
- Документ эксплуатации: приватное хранилище, ретенция, мониторинг.

### Изменено

- Порог покрытия ветвей — 90%; фактическое покрытие 94%.
- CI: матрица Django 5.2/6.0/6.1, PostgreSQL, проверка колеса, mypy на двух
  версиях django-stubs, порядконезависимые тесты.
- Релиз через PyPI Trusted Publishing: TestPyPI автоматически, PyPI после
  ручного одобрения.
- Верхние границы зависимостей; `pip-audit`, SBOM и Dependabot.

### Безопасность

- Исправлены падения на усечённом DER в CMS, сертификате и OCSP.
- Крафтовая метка времени больше не подменяет момент проверки сертификата:
  `gen_time` не влияет на срок и цепочку без доверенного TSA.
- `verify_signed_pdf` отклоняет PDF, изменённый после проверяемой подписи.
- `complete_signing` применяет `DJANGO_PDF_SIGN["VERIFY"]` по умолчанию.
- Размер CMS ограничивается до разбора ASN.1.
- Исправлены OID алгоритмов подписи RSA/ECDSA для меток времени и OCSP.
- Ночной fuzzing парсеров ASN.1.
- Allowlist хостов ограничивает сетевую загрузку отзыва; редиректы запрещены.

### Удалено

- Поддержка Django 4.2 (срок поддержки истёк в апреле 2026).

## [0.1.0] - 2026-11-08

### Добавлено

- `prepare_signing` — подготовка PDF с видимым штампом и байтами для подписи.
- `complete_signing` — проверка отсоединённой CMS и встраивание в PDF.
- `verify_cms_over_bytes` и `verify_signed_pdf` — проверка подписей.
- `VerificationPolicy` — настройка цепочки, отзыва, OCSP и меток времени.
- Поддержка ГОСТ Р 34.10-2012 / CAdES-BES (Стрибог-256/512) через `gostcrypto`.
- Поддержка PAdES / RSA-ECDSA через `pyHanko`.
- Видимый штамп с встроенным шрифтом DejaVuSans.
- Модели `SigningSession` и `SignatureRecord`, админка.
- Management-команда `pdf_sign_cleanup` для просроченных сессий.
- Настройки `DJANGO_PDF_SIGN`.
- Проверка цепочки сертификатов, CRL, OCSP и меток времени.

### Изменено

- Минимальная поддерживаемая версия Django — 5.2.
- **Django 4.2 не поддерживается**: срок поддержки истёк в апреле 2026.

### Безопасность

- Сервер не хранит закрытые ключи и PIN.
- Присланная CMS проверяется до встраивания в документ.
