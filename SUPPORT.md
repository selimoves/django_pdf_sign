# Поддержка

## Матрица версий

| Python | Django 5.2 LTS | Django 6.0 | Django 6.1 |
|--------|----------------|------------|------------|
| 3.11   | да             | нет        | нет        |
| 3.12   | да             | да         | да         |
| 3.13   | да             | да         | да         |

Django 4.2 не поддерживается: срок поддержки истёк в апреле 2026.

## Что поддерживается

- Текущая и предыдущая минорные версии пакета.
- Последняя LTS-версия Django из матрицы.
- Исправления безопасности для поддерживаемых версий.

Политика версий описана в `docs/versioning.md`, порядок раскрытия уязвимостей —
в `SECURITY.md`.
