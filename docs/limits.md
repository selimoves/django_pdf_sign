# Пределы и производительность

Замеры от 2026-11-08: Python 3.13, Windows, десктопный CPU. Значения зависят от
машины; повторить можно командой `uv run pytest -m benchmark -q --no-cov`.

## Дайджест Стрибог

`gostcrypto` реализует Стрибог на Python, поэтому хеширование — самая дорогая
операция при подписи документов ГОСТ.

| Размер | Стрибог-256 | Стрибог-512 |
|--------|-------------|-------------|
| 1 МБ | 6,2 с | 7,6 с |
| 10 МБ | 61,2 с | 76,4 с |
| 50 МБ | 360,4 с | 378,1 с |

Удельная стоимость: примерно **6–8 секунд на мегабайт**.

## Подготовка PDF

`prepare_document` (разбор, штамп, плейсхолдер подписи):

| Размер входа | Время |
|--------------|-------|
| 1 МБ | ~0,25 с |
| 10 МБ | ~0,19 с |
| 50 МБ | ~0,38 с |

Время подготовки определяется копированием байтов, а не их содержимым.

## Память

- `prepare_document` на 50 МБ: пик около **154 МиБ** (примерно 3× от размера
  файла).
- Хеширование: пик около размера входных данных.

## Рекомендации

- `MAX_DOCUMENT_BYTES` по умолчанию — 25 МиБ. Для ГОСТ это примерно **2,5–3
  минуты CPU** только на дайджест.
- Для интерактивных HTTP-запросов уменьшите лимит до 10 МиБ или вынесите
  завершение подписи в фоновую задачу.
- `BYTES_RESERVED` по умолчанию — 16 КиБ: достаточно для CMS с цепочкой и
  меткой времени.
- При лимите 25 МиБ закладывайте не менее 3 ГБ свободной памяти на процесс.
